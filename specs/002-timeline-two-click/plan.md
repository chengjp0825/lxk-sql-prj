## Implementation Design

### 1. 状态机

```
           第一次点击
IDLE ──────────────────→ SELECTING_END
  ↑                          │
  │      第二次点击(合法)      │
  └──────────────────────────┘
  ↑
  第三次点击 → 重置，以新位置为起点
```

```js
const selectionStep = ref('IDLE')   // 'IDLE' | 'SELECTING_END'
const startIndex = ref(null)        // 起点索引
const hoverIndex = ref(null)        // 悬停索引 (SELECTING_END 时有效)
```

### 2. 事件处理流程

**onClick(index)**:

```
IDLE 状态:
  if slot.status !== 'available' → ignore
  startIndex = index
  selectionStep = 'SELECTING_END'
  hoverIndex = index

SELECTING_END 状态:
  if index === startIndex → ignore (same slot)
  endIndex = index
  // 支持反向选择
  lo = min(startIndex, endIndex), hi = max(startIndex, endIndex)
  // 碰撞检测
  obstacle = findObstacle(lo, hi)
  if obstacle >= 0 → error('包含已占用时段'), reset to IDLE
  // 时长检测
  duration = (hi - lo + 1) * 30
  if duration > 240 → error('最长4小时'), reset to IDLE
  // 确认
  emit('select', { start, end, duration })
  reset to IDLE (保留 visual startIndex 用于显示, selectionStep = IDLE)
```

**onMouseEnter(index)**:

```
if selectionStep === 'SELECTING_END': hoverIndex = index
```

**onMouseLeave**:

```
hoverIndex = null
```

**第三次点击 (IDLE + 已有选区)**:

```
清空旧选区, startIndex = index, selectionStep = 'SELECTING_END'
```

### 3. 样式计算

```js
const getSlotClass = (slot, index) => {
  // 基础状态 (不可点击)
  if (slot.status === 'pending')  return 'bg-orange-400 text-white cursor-not-allowed'
  if (slot.status === 'occupied') return 'bg-gray-400 text-white cursor-not-allowed'

  // 确定有效预览范围
  let previewLo = null, previewHi = null
  if (selectionStep.value === 'SELECTING_END' && hoverIndex.value !== null) {
    previewLo = Math.min(startIndex.value, hoverIndex.value)
    previewHi = Math.max(startIndex.value, hoverIndex.value)
    // 截断：找到第一个障碍
    const obs = findObstacle(previewLo, previewHi)
    if (obs >= 0) previewHi = obs - 1
  }

  const inPreview = previewLo !== null && index >= previewLo && index <= previewHi

  // 起点标记
  if (index === startIndex.value) return 'bg-blue-600 text-white ring-2 ring-blue-300'

  // 预览范围
  if (inPreview) return 'bg-blue-300 text-white'

  // 默认可用
  return 'bg-green-500 text-white hover:bg-green-600'
}
```

### 4. 碰撞检测

```js
const findObstacle = (lo, hi) => {
  for (let i = lo; i <= hi; i++) {
    if (slots.value[i].status !== 'available') return i
  }
  return -1
}
```

### 5. Computed 选区和时长

```js
const selectedRange = computed(() => {
  if (startIndex.value === null) return null
  if (selectionStep.value === 'SELECTING_END' && hoverIndex.value !== null) {
    // 显示预览范围
    const lo = Math.min(startIndex.value, hoverIndex.value)
    const hi = Math.max(startIndex.value, hoverIndex.value)
    return { start: slots.value[lo].start, end: slots.value[hi].end }
  }
  return null
})

const duration = computed(() => {
  if (startIndex.value === null || hoverIndex.value === null) return 0
  return (Math.abs(hoverIndex.value - startIndex.value) + 1) * 30
})
```
